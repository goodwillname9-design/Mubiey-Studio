Optional Arabic calligraphy fonts for the envelope-story templates (111, 222, 333, 444, 777).
Amiri (Naskh) is already included in ../amiri.ttf and is the default.
To add the others run  scripts\get-arabic-fonts.ps1  from the project root, or save the TTF files here as:
ruqaa.ttf  kufi.ttf  nastaliq.ttf  lateef.ttf  scheherazade.ttf  katibeh.ttf  mirza.ttf  rakkas.ttf  lalezar.ttf
All of them are free under the SIL Open Font License (Google Fonts). A font that is missing simply falls back to Amiri.
